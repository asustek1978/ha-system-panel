# HA System Panel

Русифицированная системная панель для Home Assistant с Supervisor. Проект создан на основе **Pjarbit/supervisor-panel** и распространяется по лицензии MIT.

Панель возвращает отдельный пункт **«Система»** в боковое меню Home Assistant и предоставляет быстрый доступ к состоянию Home Assistant Core, Supervisor, хоста и системным журналам.

## Возможности

- интерфейс полностью на русском языке;
- версии Home Assistant Core, Supervisor и Home Assistant OS;
- индикация доступных обновлений;
- загрузка процессора и использование памяти Core/Supervisor (если статистика Supervisor API доступна);
- использование памяти и диска хоста через System Monitor;
- журналы Core / Supervisor / Host;
- поиск по журналу;
- пауза автоматического обновления журнала;
- перезапуск Home Assistant Core;
- перезапуск Supervisor;
- перезагрузка хоста;
- выключение хоста с подтверждением;
- адаптивная верстка для компьютера, планшета и телефона.

> Текст самих системных журналов намеренно не переводится: оригинальные сообщения удобнее использовать для диагностики и поиска ошибок.

## Требования

- Home Assistant OS или Home Assistant Supervised;
- Supervisor;
- рекомендуется интеграция **System Monitor** для данных о памяти, диске и загрузке системы.

## Установка через HACS

1. Откройте **HACS**.
2. Перейдите в раздел **Frontend**.
3. Откройте меню и выберите **Custom repositories / Пользовательские репозитории**.
4. Добавьте URL этого GitHub-репозитория.
5. Категория: **Frontend**.
6. Установите **HA System Panel**.
7. Добавьте в `configuration.yaml`:

```yaml
panel_custom:
  - name: ha-system-panel
    sidebar_title: "Система"
    sidebar_icon: mdi:server
    url_path: system-panel
    module_url: /local/community/ha-system-panel/ha-system-panel.js
    require_admin: true
```

8. Выполните **полный перезапуск Home Assistant**.

Если в `configuration.yaml` уже существует `panel_custom:`, второй ключ `panel_custom:` создавать нельзя. Добавьте только новый элемент `- name: ha-system-panel` в существующий список.

## Если после обновления отображается старая версия

1. Полностью перезапустите Home Assistant.
2. Обновите страницу без кэша.
3. Если это не помогло, закройте Home Assistant во всех вкладках и перезапустите браузер.

## System Monitor

Если некоторые показатели отображаются как `—`, добавьте интеграцию:

**Настройки → Устройства и службы → Добавить интеграцию → System Monitor**.

Панель автоматически ищет типовые сущности System Monitor по `entity_id`, поэтому русские названия сущностей не мешают её работе.
